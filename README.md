# Yunusemre Belediyesi Web Sitesi (Staj Projesi)

Yunusemre Belediyesi web sitesinin ana sayfası ve öneri/şikayet formu için hazırlanmış, duyarlı (responsive) ve koyu temalı bir ön yüz çalışmasıdır. Sadece HTML, CSS ve saf JavaScript kullanılmıştır; derleme aracı ya da kütüphane gerektirmez.

> **Not:** Bu proje staj kapsamında hazırlanmış bir çalışmadır, belediyenin resmi sitesi değildir. Logo, haber görselleri ve bağlantılar [yunusemre.bel.tr](https://yunusemre.bel.tr) adresine aittir.

## Kullanılan Teknolojiler

* **HTML5** - Yapısal kurgu ve içerik yönetimi
* **CSS3** - Modern yerleşim çözümleri (Flexbox, Grid, `clamp()`, medya sorguları) ve koyu tema tasarımı
* **JavaScript (ES6)** - Dinamik özellikler ve form etkileşimleri (üçüncü parti kütüphane kullanılmadan saf JS)
* **Google Fonts** - Tipografi için Poppins yazı tipi

## Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınıza klonlayın:

```bash
git clone https://github.com/selvanurKirac/yunusemre-belediyesi-staj
```

**Hızlı Çalıştırma:** Proje klasörünü açın ve `index.html` dosyasını herhangi bir internet tarayıcısında çift tıklayarak çalıştırın.
